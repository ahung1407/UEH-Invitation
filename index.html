🚀 Cách có link web để gửi Zalo/Messenger trong 30 giây (Miễn phí):

1. Vào trang app.netlify.com/drop trên trình duyệt.

2. Kéo cả thư mục chứa thiệp thả vào trang web đó $\rightarrow$ Bạn sẽ có ngay link web (ví dụ https://thiep-tot-nghiep.netlify.app).

3. Dán link đó vào ô Địa chỉ Website thiệp ở trên để gửi bạn bè là họ bấm vào xem được ngay trên điện thoại!

Tự động lưu câu trả lời vào Google Sheet của bạn thông qua Google Apps Script Web App hoàn toàn miễn phí.

📋 Cách tạo Google Sheet nhận RSVP trong 1 phút:
  1. Tạo 1 file Google Sheet mới trên Drive của bạn.
  2. Vào menu Tiện ích mở rộng (Extensions) > Apps Script.
  3. Dán đoạn code trong file google_apps_script.js vào.
  4. Bấm nút Triển khai (Deploy) > Tùy chọn triển khai mới (New deployment).
  5. Chọn loại Ứng dụng web (Web app), ở mục Ai có quyền truy cập (Who has access) chọn Bất kỳ ai (Anyone).
  6. Copy link Web App (kết thúc bằng /exec) và dán vào ô phía trên!
